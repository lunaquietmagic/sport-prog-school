  • База знаний

    • static - папка с файлами, которые не будут автоматически изменяться

    css - папка со стилями для страниц

    img - папка с изображениями

    templates - папка с HTML шаблонами (фундаментом из тегов по типу <a>)

    venv - папка с виртуальным окружением проекта, где находятся все библиотеки/фреймворки (flask, ...)

    app.py - главный файл нашего проекта (веб-приложения)

    Стандартная основа файла app.py

    from flask import Flask, render_template

    app = Flask(__file__)


    @app.route("/")

    def home():

    return render_template("home.html")


    if __name__ == "__main__":

    app.run(debug=True)
